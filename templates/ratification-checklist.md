# Ratification checklist

- [ ] Both parties and the constitution's purpose are named.
- [ ] Human and agent responsibilities are distinct.
- [ ] Disagreement and uncertainty have observable behaviors.
- [ ] Completion requires verification rather than assertion.
- [ ] Approval boundaries match reversibility and external impact.
- [ ] Public writes, messages, purchases, destruction, and new integrations are explicit.
- [ ] Memory, procedures, temporary state, and artifacts are separated.
- [ ] Privacy, least privilege, correction, and forgetting are covered.
- [ ] Stress tests pass and ambiguous clauses are resolved.
- [ ] Private details were removed from any shareable copy.
- [ ] The human approves the final text.
- [ ] The agent restates the operational changes accurately.
- [ ] The contract is deployed in an always-on layer and behaviorally tested.
- [ ] Version and changelog are updated.
