# Synthetic example

Morgan and Relay are fictional. This example exists only to demonstrate a complete, ratified schema. It does not reproduce any real person's private constitution, preferences, contacts, infrastructure, or approval history.

Render and validate it with:

```bash
.venv/bin/user-machine-constitution check sample-constitution.toml --scenarios sample-stress-tests.json
.venv/bin/user-machine-constitution render sample-constitution.toml sample-constitution.md
```
